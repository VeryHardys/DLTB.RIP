DLTB.RIP - trainer & visual mod for Dying Light: The Beast
==========================================================

[ENGLISH]

REQUIREMENTS
- Dying Light: The Beast (Steam, Windows 10/11 x64).
- Nothing else to install: no game-folder files, no Visual C++ redistributable.

INSTALL
- Extract the whole archive into its own folder (for example C:\Games\DLTB.RIP).
  Keep DLTB.RIP.exe, "Start DLTB.RIP.bat" and the "items" folder together.
- Avoid Program Files (if the folder is read-only, settings go to %LOCALAPPDATA%\DLTB.RIP).

HOW TO START - choose one way
1) From the desktop: run "Start DLTB.RIP.bat".
   It starts the game through Steam (if it is not running yet), waits for it,
   then starts the trainer.
2) While you are already playing: run DLTB.RIP.exe (Alt+Tab or a shortcut).
   No restart needed - it attaches to the running game.

Windows asks for administrator rights - this is required to work with the game's memory.
In game press INSERT to open/close the menu. END unloads the trainer (changeable in Configs).
Running DLTB.RIP.exe again while it is open restarts it cleanly.
When you quit the game, the trainer closes by itself and removes all its changes.

ITEMS TAB (Item Extravaganza)
- Items > Catalog uses Item Extravaganza's engine (included in the "items" folder
  with its author's permission). Press "Load Item Extravaganza" once per game session.
- Back up your save first. Single-player only. Changes can be autosaved.
- Do not run the original ItemExtravaganza.exe in the same game session.

NOTES
- Single-player use only. Use at your own risk; back up your saves.
- Settings are saved in the "configs" folder next to DLTB.RIP.exe (Configs tab).
- Antivirus: the trainer edits game memory and loads a DLL into the game, which some
  antivirus programs flag. Download only from the official Nexus Mods page.
- A game update can disable some features until the mod is updated.

[РУССКИЙ]

ТРЕБОВАНИЯ
- Dying Light: The Beast (Steam, Windows 10/11 x64).
- Больше ничего ставить не нужно: никаких файлов в папку игры, никакого Visual C++ Redistributable.

УСТАНОВКА
- Распакуйте архив целиком в отдельную папку (например, C:\Games\DLTB.RIP).
  DLTB.RIP.exe, "Start DLTB.RIP.bat" и папка "items" должны лежать вместе.
- Не кладите в Program Files (если папка только для чтения, настройки уйдут в %LOCALAPPDATA%\DLTB.RIP).

КАК ЗАПУСТИТЬ - один из двух способов
1) С рабочего стола: запустите "Start DLTB.RIP.bat".
   Он запустит игру через Steam (если она ещё не запущена), дождётся её и запустит трейнер.
2) Прямо во время игры: запустите DLTB.RIP.exe (Alt+Tab или ярлык).
   Игру перезапускать не нужно - трейнер подключится к запущенной игре.

Windows попросит права администратора - они нужны для работы с памятью игры.
В игре INSERT - открыть/закрыть меню. END - выгрузить трейнер (меняется в Configs).
Повторный запуск DLTB.RIP.exe корректно перезапускает трейнер.
Когда вы выходите из игры, трейнер закрывается сам и снимает все свои изменения.

ВКЛАДКА ITEMS (Item Extravaganza)
- Items > Catalog работает на движке Item Extravaganza (лежит в папке "items",
  включён с разрешения автора). Нажмите "Load Item Extravaganza" один раз за сеанс игры.
- Сначала сделайте резервную копию сохранения. Только одиночная игра. Изменения могут автосохраниться.
- Не запускайте оригинальный ItemExtravaganza.exe в том же сеансе игры.

ВАЖНО
- Только для одиночной игры. На свой риск; делайте копии сохранений.
- Настройки хранятся в папке "configs" рядом с DLTB.RIP.exe (вкладка Configs).
- Антивирус: трейнер меняет память игры и загружает в неё DLL - некоторые антивирусы
  на это реагируют. Скачивайте только с официальной страницы на Nexus Mods.
- Обновление игры может временно отключить часть функций до обновления мода.
